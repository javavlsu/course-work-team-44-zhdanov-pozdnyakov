# Image Builder Frontend

Клиентская часть системы на React + Vite.

## Технологии
*   React 18
*   Vite
*   Axios
*   CSS (Vanilla)

## Запуск
1.  Установите Node.js 18+.
2.  Установите зависимости:
    ```bash
    npm install
    ```
3.  Запустите сервер разработки:
    ```bash
    npm run dev
    ```

## Структура компонентов
*   `Header.jsx` — Навигационная панель.
*   `Editor.jsx` — Редактор образов (выбор компонентов).
*   `Login.jsx` — Страница входа.

## Взаимодействие с API
Фронтенд ожидает, что бэкенд запущен по адресу `http://localhost:8080`.
Конфигурация API вызовов осуществляется через библиотеку `axios`.
